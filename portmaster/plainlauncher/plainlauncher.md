## Notes

Plain Launcher is a free, open source emulation frontend by bokoyoss. It finds your existing ROM folders and launches games with your handheld's own RetroArch, then comes back when you quit.

* [Plain Launcher on GitHub](https://github.com/BokoYoss/plain-launcher)

## Controls

| Button | Action |
|--|--|
| D-pad / Left Stick | Move |
| A | Confirm |
| B | Back |
| X | Favorite |
| L1 / R1 | Jump by letter |
| Start | Settings |
| Select | Options |
